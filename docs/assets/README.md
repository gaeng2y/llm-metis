# Metis logo

`metis-logo.png` is the transparent M monogram used in all four READMEs. Its open center suggests a gateway. Display it at 112 pixels wide in the README; keep the surrounding area clear and preserve its proportions.

Created with the built-in `image_gen` tool. The original generated PNG is used without image edits.

## Generation prompt

Use case: logo-brand. Asset: a simple transparent brand mark for the GitHub README of Metis (llm-metis), a local gateway that helps coding agents choose tools and reasoning effort. Create one original geometric uppercase M monogram made from two mirrored thick angular strokes, with a clear central V-shaped negative space and a small open passage suggesting a gateway. Flat, clean, precise vector-like edges, consistent geometry, strong silhouette, legible at 32px. Use a single jade teal color #18A999 throughout. Center the mark with balanced margins; the mark should occupy about 78 percent of the square canvas. The background must be genuinely transparent. No wordmark or other text, no border, no enclosing tile, no gradients, no shadows, no texture, no mockup, no brain/robot/owl imagery. One finished logo mark, not a concept sheet.
